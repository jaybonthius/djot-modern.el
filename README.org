#+title: djot-modern

Modern document typography for [[https://github.com/jaybonthius/djot-mode.el][djot-mode]], inspired by Daniel Mendler's [[https://github.com/minad/org-modern][org-modern]]. Proportional prose, distinct theme-colored headings, compact labels, native-color code blocks, and thin, padded tables—without changing the Djot source.

This is an optional *minor mode*. =djot-mode= owns parsing, file associations, semantic highlighting, concealment, clickable links, native language highlighting, folding, editing, and preview/export commands. They continue working with modern disabled. Modern never installs a parser, replaces major-mode font-lock rules, or fetches document resources.

* Install and read a document

Requires Emacs 30.1+, =djot-mode= 0.1.0+, and the grammar specified in [[https://github.com/jaybonthius/djot-mode.el#readme][djot-mode's installation instructions]]. Install the major mode first. Put this package on =load-path= (or install it with your package manager), then:

#+begin_src emacs-lisp
(require 'djot-mode)
(require 'djot-modern)

;; Explicit readable-document preferences, owned by the major mode:
(setq djot-hide-markup t
      djot-descriptive-links t
      djot-src-fontify-natively t)

(defun my-djot-document-view ()
  (visual-line-mode 1)
  (djot-modern-mode 1))
(add-hook 'djot-mode-hook #'my-djot-document-view)
#+end_src

Alternatively, run =M-x djot-modern-mode= in just one Djot buffer. An explicit =(global-djot-modern-mode 1)= enables it in Djot buffers only; neither requiring the package nor installing it enables anything globally. Do not use the old =text-mode= or =djot-ts-mode= setup: this release integrates with =djot-mode=.

Open [[file:example.djot][example.djot]] to compare with [[file:example.org][the parallel Org example]]. Toggle modern to compare presentation while retaining all major-mode features. For a source-editing view use =C-c C-s= / =M-x djot-show-source=, and call it again to restore the document view. It reveals base concealment and modern structural replacements without rewriting text. Moving the cursor never changes concealment. =M-x djot-edit-at-point= explicitly reveals a link destination for editing.

* Typography and controls

All colors and font families come from your theme. Set the standard =variable-pitch= and =fixed-pitch= faces to your preferred installed fonts; modern does not choose a family. =M-x customize-group RET djot-modern= exposes these options and faces:

| Option                         | Effect                                         |
|--------------------------------+------------------------------------------------|
| =djot-modern-prose-face=        | =variable-pitch= by default; nil keeps body font |
| =djot-modern-line-spacing=      | Extra prose spacing; nil keeps buffer setting  |
| =djot-modern-headings=          | Six distinct theme colors and scaled headings  |
| =djot-modern-heading-stars=     | Per-level heading glyphs                       |
| =djot-modern-lists=             | Bullet and task glyph presentation             |
| =djot-modern-list=              | Per-source-bullet glyph mapping                |
| =djot-modern-checkbox=          | Checked/unchecked glyph mapping                |
| =djot-modern-blocks=            | Code/quote/div framing and language labels     |
| =djot-modern-block-fringe=      | Graphical block borders, respecting prefixes   |
| =djot-modern-tables=            | Display-only table alignment and thin rules    |
| =djot-modern-table-padding=     | Fixed-font-relative horizontal cell padding    |
| =djot-modern-table-vertical=    | Vertical rule width in pixels                  |
| =djot-modern-table-horizontal=  | Compressed separator-row height                |
| =djot-modern-inline=            | Attribute labels and raised/lowered scripts    |
| =djot-modern-replace-markers=   | Nil keeps structural source markers visible    |

Re-enable the mode after changing options. Theme and font changes refresh frame-dependent measurements automatically. Individual =djot-modern-heading-1= through =djot-modern-heading-6= faces control scales while inheriting the corresponding major-mode/outline color, not one shared heading color.

Technical regions use =djot-modern-fixed-pitch=, =djot-modern-code= and =djot-modern-table=. Code faces do not override native token foregrounds; code backgrounds are subtly derived from the current theme. Quotes retain the prose family. Attribute labels keep every key, value and comment; only their braces become padding. Code and raw contents, escaped characters, and invalid syntax are never replaced. Subscripts/superscripts use real Emacs display height/raise properties rather than Unicode lookalikes.

Tables use semantic pipe tokens, not a regexp split: literal pipes in code and escaped pipes remain ordinary cell text. Graphical presentation computes visible cell widths, including effective foreign replacement displays such as the major mode's explicit local-image/math previews, honors left/right/center alignment, and uses stretch spaces for thin rules and padding. It changes neither source whitespace nor the undo list. =M-x djot-table-align= remains the explicit source-alignment command. Repeated alignment with modern on or off must produce the same source; after changing source visibility, explicitly align again if you want the newly visible source columns aligned. Terminal frames retain source table layout and fixed-pitch styling.

* Lifecycle and integration

Modern reuses the major mode's single =djot-parser= and =djot-after-fontify-hook=. It owns only overlays marked =djot-modern= and its face-remap cookies. Disable removes these even in a narrowed buffer and restores its line-spacing setting without reverting subsequent user changes. Other overlays, display/prefix properties, link maps, base invisibility and native token faces remain owned by their original packages.

Presentation overlays are not copied into killed/copied text. Selection, search, point, source, undo, and modified status remain source-based. Refontification is bounded; editing a table invalidates that table's display layout because another row's column width may need to change. No document code is executed by modern. Preview commands belong to =djot-mode= and work with modern off; their display changes invalidate table layout without changing source. Other extensions changing replacement displays should request =djot-refresh= so layout can be remeasured.

* Development and visual proof

#+begin_src sh
make check DJOT_MODE_DIR=../emacs-djot-mode GRAMMAR_DIR=/path/to/grammar
make integration GRAMMAR_DIR=/path/to/grammar
make benchmark GRAMMAR_DIR=/path/to/grammar
make clean
#+end_src

=check= runs warning-as-error byte compilation, Checkdoc and lifecycle/integration ERT, including composed table editing and empty-cell grammar regressions. =integration= reruns the test suite without compilation. These are hard assertions, not grammar-dependent skips. =benchmark= measures base fontification, modern activation, bounded edits and disable at 20/100/300 headings with the actual parser.

Run the graphical driver under Xvfb or on an isolated display:

#+begin_src sh
mkdir -p /tmp/djot-modern-gui
DJOT_GUI_DIR=/tmp/djot-modern-gui GRAMMAR_DIR=/path/to/grammar \
NO_AT_BRIDGE=1 xvfb-run -a /path/to/graphical/emacs -Q \
  -L . -L ../emacs-djot-mode \
  -L /path/to/org-modern -L /path/to/compat -l test/gui.el
#+end_src

The driver compares the actual Org-modern implementation with Djot-modern under Modus light/dark themes, with the same body/fixed fonts, heading scales, wrapping and spacing. It exports PNGs of prose/headings/attributes and quotes/code/tables, plus modern-off and explicit-source views. The driver also tests actual font families and script positions, pixel-aligned column boundaries, right/center alignment, incremental table edits, and preservation of distant link overlays. Its preview-composition regression requires graphical SVG support and real =latex= / =dvisvgm= tools; it checks wide local-image and rendered-math cells, display-only invalidation, clearing, source visibility, modern on/off, theme/font-size changes and repeated source alignment. It records the resolved fonts and fails with an =error.txt= artifact rather than leaving Emacs in a debugger. These screenshots require visual inspection; passing face/property tests alone does not prove appearance.
